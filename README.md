Descripcion

Proyecto desarrollado en Java que permite explorar y administrar archivos y carpetas desde una interfaz grafica.

Funciones principales

Explorar archivos y carpetas.

Buscar archivos mediante filtros.

Identificar archivos duplicados.

Consultar estadisticas.

Crear, copiar, mover, renombrar y eliminar archivos y carpetas.

Consultar la bitacora de acciones.

Guardar configuraciones.

Generar reportes.

Tecnologias utilizadas

Java 17

Apache NetBeans IDE 17

Java Swing

Estructura del proyecto

modelo: contiene las clases principales y la logica del programa.

GUI: contiene la interfaz grafica.

Adaptador: conecta la interfaz con el modelo.

Ejecucion

Abrir Apache NetBeans.


Abrir el proyecto.

Ejecutar el programa.
